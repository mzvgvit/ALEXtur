# SPEC — сайт ALEXtur

Дата: 2026-11-13. Актуализируется при изменениях структуры.

## 1. Цель сайта и целевая аудитория

**Цель:** продать авторские путешествия «под ключ»: Италия — русским, мир — итальянцам, Италия и Россия — от края до края. Сайт знакомит, собирает доверие (отзывы, FAQ, реквизиты) и приводит к заявке через WhatsApp/mail.

**Целевая аудитория:**
- Русскоязычные путешественники (25–60 лет), ищущие экскурсии и туры в Италию без языкового барьера, под ключ.
- Итальянцы и иностранные гости: туры по миру и по России с полной организацией, включая визы.
- Контент-направление: блог — витрина компетенции, работает на доверие и SEO; обзор на ~1000 знаков обязателен к фотографии.
- Отдельный продукт: ретриты (лендинг `retreat/`) — три заезда 2027 года: перезагрузка в Тоскане, кухня Апулии, архитектура и традиции Венето. Выбор по `?tour=tuscany|puglia|veneto`; новые программы публикуются с предварительными ценами до подтверждения партнёров.

**Ключевой отклик на всех страницах:** заявка в WhatsApp (`wa.me/393885758059`) или почта `booking@ALEXtour.com`.

## 3. Технический стек

- **Чистый статический сайт**: HTML5 + CSS + ванильный JS, без сборки и фреймворков. Работает при открытии файлов локально и с любого статического хостинга.
- **i18n**: русский — в разметке (SEO/доступность без JS); en/it — словари `js/i18n.js` (главный сайт, плоские ключи, `data-i18n*` атрибуты) и встроенный словарь ретрита. Хранилище выбора языка: `localStorage['alextur-lang']`.
- **Данные**: `data/blog-data.js` (объект `window.BLOG_COUNTRIES` — 45 стран × {n,r,d,s,t} × 3 языка); инвентарь — `data/site-inventory.md`.
- **Медиа**: только Wikimedia Commons (свободные лицензии), атрибуция в `img/photo-credits.md`. Локальные копии в `img/`; у ретритов есть адаптивные производные `-640.jpg` и `-960.jpg`, подключаемые через `srcset`/`sizes`. LCP-фото — `<img fetchpriority="high">`, не CSS-фон.
- **Отзывы/заявки**: демо-хранилище localStorage; реальный приём не подключён (TODO: Formspree/Telegram-бот).
- **Анимации**: CSS keyframes + IntersectionObserver (reveal), счётчики, таймлайн; всё отключается при `prefers-reduced-motion`.
- **Современные API**: модалки ретрита — нативные `<dialog>` с `showModal()`, `closedby="any"` и fallback для Safari; тяжёлые секции ниже первого экрана используют `content-visibility:auto` с зарезервированным размером.
- **Проверки качества**: `node --check` всех JS; ключи i18n и ресурсы сверяются скриптами перед релизом.

## 4. Дизайн и стилистика

- **Палитра** (переменные `css/style.css`): оливковая гамма `--olive-50 #F4F6E8 … --olive-900 #383B1B`, акцент терракота `--accent #C4652F`, бумага `--paper #FDFDF7`, чернила `--ink #2B2A20`. Ретрит — те же цвета, отдельная верстка.
- **Типографика**: системный стек `'Segoe UI',system-ui,-apple-system,Roboto,Arial` (без веб-шрифтов для скорости); H1 clamp-размеры; выделения `em` терракотой.
- **Компоненты**: скругление `14px`, мягкая тень `0 8px 28px rgba(56,59,27,.14)`; кнопки-пилюли (solid olive / ghost с inset-рамкой); чипсы-теги; плашки цены терракотой; карточки с фото 16:10.
- **Шапка/подвал**: тёмно-оливковые `#383B1B`, sticky-шапка, мобильные меню `< 860px`.
- **Тон текстов**: живой, по-человечески, без канцелярита; юмор дозированно; каждый обзор статьи ~900–1000 знаков; факты сверяются с фотографией.
- **Визуальная дисциплина**: фото — только реального места/страны статьи; заглушки-фолбэки оформлены одинаково (оливковый градиент+подпись).

## 6. Текстовые заглушки секций

Шаблоны текстов. `<страна>` подставляется языковым полем `n`.

| Секция | Заглушка |
|---|---|
| Hero (index) | H1: «Отпуск, о котором вы мечтали, — под ключ». Подтекст: «Опишите свою идеальную Италию — остальное сделаем мы: …» |
| Карточка направления | `<Направление> · <регион>` / тизер до 60 зн. `d` / цена «от €35» |
| Карточка блога | Заголовок: `<страна> <регион>`; teaser: `d` (до 60 зн.); кнопка «Читать статью →» |
| Статья блога | H1 `<страна>`; обзор `s` 900–1000 зн.; советы `t` (3 чипса); CTA «Заказать тур по этой стране» |
| Отзыв | Имя (1–2 сл.), город, тур, месяц-год, текст 200–400 зн., 1–5 звёзд |
| Миссия | Манифест: «Мы возвращаем путешествиям главное — ощущение, которое остаётся после…» |
| FAQ | Вопрос (1 строка) + ответ (1–3 предложения, факт + обещание) |
| Ретрит: программа | День N: заголовок 3–5 сл. + 1–2 предложения «что происходит» + плашка «включено: …» |
| Ретрит: видео-карточка | `<Заголовок>` + `<описание·длительность>`; тег «скоро», если видео нет |
| Ретрит: заявка | Форма: Имя*/WhatsApp*/E-mail*/Заезд/Комментарий; итог — WhatsApp с готовым текстом |
| Липкая CTA | «До заезда <даты> осталось <N> мест» + кнопка «Записаться» |

Правила заглушки: писать живо, без «коммерческого мыла»; числа сверять между страницами (72 города · 268 гидов · 158 525 отзывов · 4,98).
