# Инвентарь проекта — обновлён 2026-11-14

## Структура

| Путь | Что это |
|---|---|
| `SPEC.md` | Спецификация сайта: цель, ЦА, секции, стек, дизайн, структура, заглушки |
| `index.html` … `rome.html`, `reviews.html`, `about.html` | 9 страниц главного сайта, все трёхъязычно (ru в разметке + en/it из словаря) |

| `js/i18n.js` | Словарь главного сайта (240 ключей × 3 языка) + переключатель языков |
| `js/shared.js` | Шапка/подвал/переключатель всех страниц главного сайта |
| `js/main.js` | Фолбэки картинок |
| `js/blog.js` | Движок блога: дневная подборка, карточки, статьи (данные берёт из `data/blog-data.js`) |
| `js/reviews.js` | Отзывы: витрина + демо-форма (localStorage; TODO — реальный приём отзывов) |
| `data/blog-data.js` | Данные блога: 45 стран × (n, r, d, s-обзор ~1000 знаков, t-советы) × 3 языка |
| `data/site-inventory.md` | Этот файл |
| `obzor/` | Обзоры достопримечательностей (8 шт, даты-имена `YYYY-MM-DD-тема-obzor.md`); фото к ним — в `img/ china/…` |
| `img/italy/` | Фото Рима/Италии (7 шт) |
| `img/china`, `img/mexico`, `img/morocco`, `img/vietnam/` | Фото новых обзоров obzor/ (по 2 шт) |
| `img/blog/` | Фото-обложки стран блога (45 шт + адаптивная производная `italy-640.jpg` для галереи Венето) |
| `img/logo/` | favicon (используется), logo-horizontal.svg и logo-mark.svg — резервы для соцсетей/печати |
| `img/photo-credits.md` | Атрибуция всех фото/видео (Wikimedia Commons, сводные лицензии) |

## Правила, с которыми живём

- Файлы документов: `[YYYY-MM-DD-]тема-тип.md` латиницей; ключи/пароли — только в корне, в git не идут.
- Служебное, от чего зависят скрипты (`data/blog-data.js`, `img/blog/*.jpg` по `id` страны), не переименовывать.
- Свободные медиа — только с лицензией, источник пишем в `img/photo-credits.md`.
